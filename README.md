# 排版工作台

这是一个固定模板的本地排版工具，不需要安装 npm 依赖。

## 使用

1. 在项目目录执行 `npm start`（也可以执行 `node src/server/index.js`）。
2. 把 Markdown 文章内容直接粘贴到左侧输入框。
3. 在固定顶部栏选择排版风格：空心红、橘红或红色长轮。默认使用第一种“空心红”。
4. 右侧会立即显示排版预览。
5. 点击“复制到公众号”，生成的富文本会直接进入剪贴板。打开微信公众号正文编辑器，按 `Ctrl+V` 即可粘贴。
6. 如果还需要保留文件，点击“下载 HTML”。文件名为：

   `{文章名}_排版_{风格名}.html`

工具会自动处理章节编号、粗体序号标题、引用、列表、正文图片、人物案例隐私说明、顶部卡片占位符和文末点赞组件。人物案例文章的顺序固定为：卡片占位符 → 案例说明 → 正文。

章节标题会在达到当前样式的长度阈值后自动换行：换行点优先选择标点和语义词边界，并保留常见中文复合词（例如“心理健康”“生活方式”）的完整性，不依赖第三方分词包。空心红、橘红和红色长轮均使用这套本地规则。

点击顶部“封面图”可以打开提示词组装弹窗。模板、场景、时间和光线、主体、构图以及负面提示词均保存在 `src/cover/content.js`，后续扩展选项只需要编辑这个内容文件，不需要改动弹窗逻辑。

复制和下载时，工作台会自动内嵌模板自带的图片素材。粘贴进输入框的 Markdown 无法授权浏览器读取电脑上的相对图片路径；正文图片请使用可访问的网络图片地址。

## 浏览器要求

建议使用最新版 Chrome 或 Edge。新的直接输入流程不需要选择目录或授予目录权限，文章内容只在本机处理，不上传文件。
